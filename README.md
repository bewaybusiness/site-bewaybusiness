# BEWAY - Estrategia e Capital

Construa o novo site institucional da BEWAY — Estratégia e Capital — como projeto independente dentro deste workspace. Não modifique, clone ou reutilize o projeto Montesinai Obras.

OBJETIVO E POSICIONAMENTO
A BEWAY é uma empresa de estratégia e capital. Slogan: “Direção para crescimento.” Descritor oficial: “Aconselhamento e viabilização de investimentos para crescimento empresarial.”
A BEWAY combina capital intelectual (análise, conhecimento, aconselhamento e orientação de decisões) e viabilização de capital financeiro para oportunidades de crescimento. Lógica institucional: CONSELHO → CAPITAL → CRESCIMENTO.
A BEWAY aconselha, analisa, orienta decisões, estrutura oportunidades e viabiliza investimentos. Não se apresentar como agência, consultoria operacional, assessoria financeira genérica ou executora de campanhas/projetos/operações. Não prometer resultados nem sugerir execução operacional cotidiana.
A percepção deve ser de inteligência estratégica, critério, discrição, precisão e relações seletivas. Exclusividade deve decorrer do critério, nunca de arrogância ou inacessibilidade artificial.

FORMATO
Site institucional one-page, em português brasileiro (pt-BR), sem catálogo de serviços, blog, login, banco de dados, autenticação, Supabase, painel administrativo, formulário ou funcionalidades desnecessárias. Construir uma página completa, responsiva, rápida e fácil de manter. Usar o stack padrão Lovable (TypeScript, Tailwind e shadcn/ui quando fizer sentido), com componentes simples e código organizado. Evitar dependências desnecessárias.
